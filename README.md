# Google Keep 窄窗布局

`google-keep-layout.user.js` 是 Tampermonkey 油猴脚本，版本 0.7.0。
`create-shortcut.ps1` 建「Keep 窄窗」快捷方式。

## 仓库

GitHub 仓库 `chasezhang1999/google-keep-layout`（2026-10-22 起），各台电脑以它为准。
新电脑上拉到 `D:\Code\google-keep-layout`：`gh repo clone chasezhang1999/google-keep-layout D:\Code\google-keep-layout`，
再按下面「安装和更新」装脚本、建快捷方式。`node_modules` 不进库，要跑测试先 `pnpm install`。

## 做什么

1. **缩小图标**：顶栏、新建记事栏右侧三个按钮、左侧菜单按同一比例缩小（默认 75%）。
   - 顶栏 64→48（窄窗时 56→42）；
   - 窗口很窄时藏起顶栏的「Keep」字样，给按钮让位；去掉 Keep 页面 360px 的最小宽度。
2. **左侧菜单改成下拉**：平时完全收起、不占宽度，记事铺满整个窗口；
   点左上角菜单按钮展开，再点收回（默认宽 180，每行 28.5）。
   选了一项、点到菜单外、按 Esc 都会自动收起。菜单文字跟着缩小（默认 14→12px，最小 12px）。
3. **窗口能拖得很窄**：用「Keep 窄窗」快捷方式打开 Keep，窗口能拖到约 180（屏幕单位，PC 上约 220 像素）。
   脚本记住这个窗口的大小和位置，下次打开自动摆回去。
4. **卡片更紧凑**：标签芯片高 20px、文字 11px；列表里的卡片不显示底部操作栏，也不给它留空白。
5. **点卡片就地编辑**：编辑框出现在卡片原来的位置、宽度不变，底下多出工具栏，同一列下面的卡片往下让；
   没有灰色遮罩，页面照常滚动，打开、关闭都不动滚动条。编辑框用蓝色边框标识。
   点 `×`、点页面空白处、按 Esc 退出；编辑时点另一张卡片直接换过去。
   编辑框还是 Keep 自己的，保存、撤销、图片、清单都照旧。
6. **标签按钮**：编辑框（和新建记事栏）里的「协作者」按钮换成标签按钮，一点就打开 Keep 的标签选择框，
   不用再进 More 菜单。编辑框里因此没有协作者入口了（按 Chase 的要求「替换」，不另外往 More 里加）。
7. **窄窗编辑栏**：按钮缩到 28px，一行放不下就换行；Close 换成 `×` 图标，和其他按钮一样大、一样对齐。
8. **置顶用边框标识**：置顶的卡片是暖色边框，「Pinned / Others」分组标题不显示；右上角图钉小一号。

窄窗时 Keep 自己会变成单列、卡片铺满宽度，列表/网格切换按钮会被藏起来，
这时可以按 **Ctrl + G** 切换列表和网格视图。

## 左侧菜单怎么改的

- Keep 的菜单是 `.PvRhvb`：收起时带 `.PvRhvb-qAWA2`，占位块 `.PvRhvb-fozPsf-ysyhld` 撑出宽度，
  菜单面板 `.PvRhvb-bN97Pc` 固定在左边。脚本把占位块宽度设成 0，面板改成顶栏下方的下拉：
  收起时 `visibility: hidden`，展开时用 `clip-path` 从上往下露出。开关仍由 Keep 自己的菜单按钮控制。
- Keep 点完选项、点到菜单外都不会自己收起，脚本替它点一下菜单按钮（这样 Keep 自己记的状态、
  按钮的 `aria-expanded` 都对得上）。菜单按钮按标准菜单图标（`path d="M3 18h18v-2H3v2z…"`）认，
  认不到就认顶栏里唯一带 `aria-expanded` 的 div 按钮。
- Keep 在宽窗时把「菜单开着」记在 localStorage 的 `keep_db::left_nav_menu_open_state`（"true"/"false"），
  下次打开页面就是开着的、会盖住记事。脚本在页面最开始把 "true" 改成 "false"；页面加载完时还开着就关上。
- 再点一次菜单按钮要收起：窄窗时 Keep 在按下鼠标时就把开着的菜单当「点到外面」关掉，紧接着按钮的 click
  又把它打开。脚本在按下时记下菜单开没开，到 click 时发现已经被关掉，就拦下这次 click。

## 就地编辑怎么做的

原则：编辑框、按钮、菜单全是 Keep 自己的，脚本只加一段样式，再在编辑期间做几件小事；不往 Keep 的页面里插节点，
也不改 Keep 写在卡片上的位置（Keep 的拖动排序靠它）。

- **列表**：底部操作栏在页面一开始就用样式藏掉，Keep 排版时量到的卡片高度里没有底栏，自己就排紧了。
- **打开**：Keep 打开记事时在 body 上加 `XKSfm-L9AdLc-prCEue-uA7qgc`、给原卡片加 `IZ65Hb-fbudBf`。
  脚本看到后给编辑框加 `kc-inline`：绝对定位到原卡片的位置和宽度，去掉遮罩和动画，高度随内容。
  直达链接打开、列表里找不到原卡片时，保留 Keep 原来的弹窗。
- **让位**：同一列里原卡片下面的卡片用 CSS `translate` 往下推「编辑框高度 − Keep 给原卡片留的空间」，
  分组底部加同样多的 `margin-bottom`。只在编辑期间每帧对一次，打字变高、Keep 重排、窗口变宽都跟得上。
  留的空间按「到下一个元素的距离 − 两者本来的间距」算，不拿原卡片现在的高度：打字时 Keep 会先把藏着的原卡片撑高、
  过一会儿才重排下面的卡片。
- **滚动**：
  - Keep 打开编辑框后，会把落在编辑框上的老式 `mousewheel` 事件 `preventDefault` 掉（本来是只让编辑框正文自己滚），
    就地编辑时就成了页面滚不动。编辑期间在编辑框和列表上滚动的事件不让 Keep 收到。
  - 打开时 Keep 对编辑框调一次不带 `preventScroll` 的 `focus()`。脚本在按下卡片的那一刻（Keep 还没开始打开）
    就把编辑框摆到这张卡片上，并记下滚动位置；万一还是滚了，在画出来之前拉回。
  - 编辑框加了 `overflow-anchor: none`：不然浏览器会拿编辑框里的元素当滚动锚点，打开后图片、正文陆续撑开时，
    为了让锚点不动把整页往下滚（编辑框超出屏幕底部时就会这样，10-27 实测滚了约 300px）。
  - 关闭时 Keep 两次调不带 `preventScroll` 的 `focus()`：关的那一刻 focus 编辑框里的卡片（Keep 的弹窗是固定定位的，
    不会滚；原位编辑框不是，没露全时浏览器就把页面滚过去），退场动画放完再 focus 列表里原卡片中的一层。
    脚本从开始编辑到退场结束都记着页面滚到哪（自己滚的也算）：第一次在关闭的同一轮任务里拉回，
    第二次在 `focusin`（这时已经滚了、滚动事件还没派发）里拉回，都在画出来之前。编辑框里的焦点变化不管，Tab 到哪就该看到哪。
- **退出**：`×` 就是 Keep 自己的 Close，只是字换成图标；Esc 在编辑框里由 Keep 自己处理，焦点不在编辑框里时脚本替它点 `×`；
  点页面空白处（列表、顶栏、侧栏）脚本替你点 `×`；点另一张卡片不关，让 Keep 直接换记事。
  Keep 关闭后还要放 1 秒退场动画，脚本立刻藏起编辑框、露出原卡片，等 Keep 真藏起编辑框再撤掉 `kc-inline`。
- **标签按钮**：协作者按钮（`.euCgFf`）的按下、松开、点击都在捕获阶段拦下，不给 Keep；点击时替你点 More，
  再点菜单里文字含 label / 标签 的那一项（「添加标签」「更改标签」）。找的时候先把 More 菜单藏住，不让它闪一下；
  600ms 内认不出这一项（Keep 改版或翻译不同）就不藏了，把 More 菜单留给你自己点。
  Keep 的按钮要按下、松开、点击三个鼠标事件才动作，单独 `.click()` 不够；油猴隔离环境里的 `window` 是代理，
  不能当 `MouseEvent.view` 传给页面，所以不带 `view`。

## 为什么要另开一个窗口

「安装成应用」的 Keep 窗口最窄 500（PC 上 125% 缩放，就是 625 像素）。这是 Chromium 写死的：
`chrome/browser/ui/views/frame/layout/browser_view_app_layout_impl.cc` 里
`if (is_web_app_) contents_size.SetToMax(gfx::Size(kMainBrowserContentsMinimumWidth, 1));`，常量是 500。
Windows 连程序调整窗口大小也按这个最小值卡住，所以鼠标拖、网页 `window.resizeTo`、外部工具都过不去
（0.3.0 的「窗口宽度…」就是因此在应用窗口里无效，0.4.0 已删除）。
Edge 也一样（10-22，Edge 155）：装成应用的窗口同样拖不窄（Chase 自查）；`--app` 窗口和普通窗口的最窄宽度
与 Chrome 155 分毫不差（ASUS 上实测 178 / 516 屏幕单位），窗口这部分是同一份 Chromium 代码，换 Edge 没用。

用 `chrome --app=网址` 打开的窗口不算已安装的应用，没有这条限制，标题栏只有图标和最小化/最大化/关闭。
但这种窗口 Chrome 不记大小位置（每次都以默认大小打开），所以由脚本来记：只在地址带 `#kc-narrow`
的窗口里生效（标记存进 sessionStorage，Keep 改了地址也认得），先改大小再挪位置
（反过来会被 Chrome 推回屏幕内）；Chrome 摆出来的高度常比要求多一两个单位，
所以只在你自己拖动或挪动后才保存，不会每次打开都长高一点。最大化时不保存。

## 安装和更新

1. **油猴脚本**：
   - **一键安装 / 更新**：在装有 Tampermonkey 的浏览器里直接打开 [`google-keep-layout.user.js` (Raw)](https://raw.githubusercontent.com/chasezhang1999/google-keep-layout/main/google-keep-layout.user.js)，油猴会自动弹出安装或升级界面；日常也可通过 Tampermonkey「检查更新」自动拉取最新版。
   - **手动粘贴**：打开 Tampermonkey 控制面板，点开「Google Keep 窄窗布局」（没装就「添加新脚本」），把 `google-keep-layout.user.js` 的全部内容粘贴进去替换原有内容，按 Ctrl+S 保存，再刷新或重开 Keep。脚本名和命名空间与旧版相同，会替换旧版。只改磁盘上的文件不会更新已安装的脚本。
2. **快捷方式**：PC、ASUS 上已建好（桌面和开始菜单里的「Keep 窄窗」）。别的电脑上运行：
   `powershell -ExecutionPolicy Bypass -File create-shortcut.ps1`
   （Chrome 用户资料不是 Default 时加 `-ChromeProfile "Profile 1"` 之类）。
   想固定到任务栏：右键快捷方式 →「显示更多选项」→「固定到任务栏」。
   快捷方式写着和窗口相同的任务栏身份（AppUserModelID `Chrome.keep.google.com_/`），固定后图标和打开的窗口是同一个，
   点它会切到已开的窗口。10-22 之前建的快捷方式没写这个，固定后会另起一个图标、点一次再开一个窗口：
   重跑一次脚本，取消原来的固定，再重新固定。
   快捷方式的图标用的是脚本复制到 `%USERPROFILE%\.google-keep-layout\keep.ico` 的那份，不是项目文件夹里的：
   ASUS 的 `D:\Code` 带沙箱加的权限规则，引用这里面的图标会显示成白纸；也不能放 `%LOCALAPPDATA%`，
   在 Claude / Codex 会话里跑脚本时，新建到那里的文件会被 MSIX 容器转存，资源管理器看不见，同样是白纸。
3. 用「Keep 窄窗」打开 Keep，第一次是默认大小，拖到想要的宽度、放到想要的位置；以后打开就是这个样子。
4. **发布到 GreasyFork**（10-22 起）：发布页的「附加信息」用 `greasyfork-description.md`（格式选 Markdown），
   脚本语言选「中文 (简体)」。脚本头部为此加了 `@license MIT`。

脚本完全不起作用时：

- 在 Chrome 地址栏打开 `chrome://extensions`，进 Tampermonkey 的「详细信息」，
  确认「允许用户脚本」已开启（Chrome 138 起需要）；
- 确认油猴总开关和本脚本开关都开着，并允许它在 `keep.google.com` 运行。

## 设置

**图标缩放…**：50–100（%），默认 75，在 Tampermonkey 菜单里，管顶栏、新建栏按钮和左侧菜单（菜单文字最小 12px）。
窄窗口的标题栏没有扩展图标，要在装好的 Keep 应用或普通标签页里打开 Keep，
点扩展图标（拼图）→ Tampermonkey 设置；各个窗口共用这个设置。

## 版本

- 0.7.0（2026-10-27）：在 0.5.0 上重写 Codex 0.6.x 想做的几件事（紧凑标签、就地编辑、× 、标签按钮、编辑栏换行、
  菜单再点收起、置顶边框）。Chase 装上 0.6.5 后反映退不出编辑、卡片错位重叠、拖动和滚动卡、标签和菜单不对，
  在真实页面上查到的原因：
  - Esc 被脚本拦下、转去点一个藏起来的 Close，退不出；`×` 是脚本另插的按钮，点的也是藏着的那个；
  - 浏览时脚本自己挪卡片位置，还监听 HTML5 拖放（Keep 不用它），和 Keep 的排版、拖动排序打架，错位重叠；
  - 全局 MutationObserver 每次变化都扫整页，拖动、滚动时卡；
  - 置顶边框加在卡片外层，外层没有边框，看不见；
  - 关闭时和 Keep 1 秒的退场动画叠在一起，闪。
  0.7.0 只加样式、用 Keep 自己的按钮，编辑期间才跟踪原卡片。协作者不再挪进 More（见「做什么」第 6 条）。
  0.6.x 没有进 git、也没有存档；原文在 ASUS 上 10-27 的 Codex 会话 `01a17b47-fd6c-7463-ac08-9e5bd04bae15` 的记录里。
- 0.6.0–0.6.5（2026-10-27，Codex）：见上，已被 0.7.0 取代。
- 0.5.0（2026-10-21）：左侧菜单改成点菜单按钮后从上往下展开的下拉，平时不占宽度；菜单文字跟着缩小（最小 12px）。
- 0.4.0（2026-10-21）：删掉 0.3.0 的「窗口宽度…」（应用窗口最窄 500，调不动）；
  改为「Keep 窄窗」快捷方式 + 记住窄窗口的大小位置。
- 0.3.0（2026-10-21）：缩小图标和菜单；去掉 0.2.x 的卡片重排和右下角「布局」按钮
  （窄窗时 Keep 自己就单列铺满；重排会破坏拖动排序）。0.2.1 原样存档在 `archive/0.2.1/`
  （10-22 起随整个文件夹进了 GitHub 私有库）。
